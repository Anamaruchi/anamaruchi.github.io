Tutorial Kartu Flazz - Emoney - Brizzi

Download | File Module Tutorial Kartu Flazz - Emoney - Brizzi
Kartu Flazz BCA, EMoney Mandiri & Brizzi BRI Memiliki Ukuran Standar ID Card Yaitu 5,4x8,6cm, Untuk Settingnya tidak jauh beda dengan Setting ID Card UV, Hanya saja memiliki Setting UV Tinta White pada saat Print.

Cara Memberikan Tinta Putih UV Pada Photoshop :
1. Select Area yang akan diberikan Tinta Putih UV lalu Pergi ke Tab Channels, Perhatikan Panah pada Gambar Bawah

2. Buat Layer baru pada Tab Channels, Perhatikan Panah pada Gambar Bawah

3. Setelah itu Klick Kanan Select Inverse lalu Tekan Ctrl + I, Perhatikan Panah pada Gambar Bawah

4. Ubah Layer Alpha 1 yang baru di buat menjadi Nama "1", Pilih "Spot Color", Ubah Solidity menjadi "100%", Perhatikan Panah pada Gambar Bawah

5. Lalu Copy Spot Channel 1, menjadi ada 2, dan ubah 1 nya lagi menjad Name "2", Perhatikan Panah pada Gambar Bawah

6. Selanjutnya Nyalakan Semua Icon Mata pada Tab Channel, Perhatikan Panah pada Gambar Bawah

7. Terakhir Tinggal Save PDF dengan Settingan yang sama, Perhatikan Panah pada Gambar Bawah

Penamaan Spot Channel Pada UV :
Nama "1" = Tinta White
Nama "2" = Tinta White
Nama "3" = Tinta Vernish
Nama "4" = Tinta Vernish
Catatan Penting: Selalu Buat Double Spot Color pada UV, Contoh Buat Spot Color White 1 & 2
Untuk Rename File Kartu Flazz, EMoney, Brizzi bisa seperti dibawah
Hijau = Nama Customer
Kuning = Nama File yang berada didalam
Merah = Ukuran Jadi File
Biru = Print 1 Sisi / 2 Sisi
Oren = Berapa Pcs Cetak

Lalu, Jika Kamu Sudah Selesai Setting, Flazz/EMoney,Brizzi, Full Black & Markahnya, Combine Menjadi 1 PDF, Page 1 [Markah] - Page 2 [Full Black] - Page 3 [Print], Bisa dilihat gambar dibawah :




Cara Cek Spot Color pada PDF, Untuk Mengetahui Apakah Setting File Berhasil atau Tidak :
1. Buka PDF yang Ingin di Cek, Lalu Pergi ke Tab Tools, Perhatikan Panah pada Gambar Bawah

2. Setelah Klick Print Production, Klick Output Preview pada bagian Kanan Menu di PDF, Perhatikan Panah pada Gambar Bawah
3. Arahkan Cursor Mouse pada Halaman Print yang terdapat Spot Channel Colornya, Jika berubah menjadi 100% berarti berhasil, Perhatikan Panah pada Gambar Bawah
