Tutorial Hard Cover

Download | File Module Tutorial Hard Cover
Hard Cover adalah salah satu Jenis Jilid/Binding pada Buku, Hard Cover adalah Proses Menjilid Buku namun untuk Covernya Keras karena Menggunakan Board.

Untuk Setting Hard Cover hampir sama dengan Soft Cover hanya saja ada sedikit perbedaan pada Settingan Punggungnya, kamu bisa gunakan Software apapun yang kamu kuasai, tapi disini Saya hanya akan memberikan Tutorial Berdasarkan Menggunakan Software Adobe Photoshop, dikarenakan Metodenya sama saja.

Cara Setting Hard Cover :
1. Masukan File Cover ke Photoshop, dan pastikan Ukuran sudah sesuai Buku Ukuran Jadi nantinya, Perhatikan Gambar

2. Tambahkan Canvas 0,7cm [Wajib] Sebelum Ukuran Tebal Buku, Perhatikan Gambar Bawah

3. Setelah Itu Baru Tambahkan Canvas Sesuai Tebal Ukuran Buku Nanti, Perhatikan Gambar Bawah

4. Setelah Menambahakan Canvas Untuk Tebal Buku Nanti, Kamu Tambahkan Canvas Lagi 0,7cm [Wajib], Perhatikan Gambar Bawah

5. Terakhir Tambahkan Canvas lagi berdasarkan sama ukuran dengan Cover Depan juga, Perhatikan Gambar bawah

6. Lalu Sesuaikan dengan Cover Belakang, Punggung juga, Perhatikan Gambar bawah
7. Tambahkan Canvas Lagi, Minimal 3cm Keliling atau 1,5cm Tiap Sudut untuk Bleed Lipat Ke Dalam Board Hard Cover Nanti, Perhatikan Gambar bawah

8. Setelah Sudah Menambahkan Canvas, Kamu Content Aware dengan Rapih dan Menambahkan Kress berdasarkan seperti Gambar dibawah, Perhatikan Panah Merah
9. Setelah Selesai Kamu bisa Save ke PDF Langsung atau JPG dahulu baru di PDF'kan

Note Penting :
• Untuk Punggung Ingin Terdapat Content/Tulisan Isi Minimal adalah 0,8cm, dibawah itu akan Rawan Miring saat Prosess Menjilid Hard Cover

Cara Setting Punggung :
• Antar Jarak Pinggir Kiri Kanan Punggung ke Isi Content Minimal 0,15cm, Perhatikan Gambar Bawah

Cara Mengatahui Tebal Buku Untuk Setting Hardcover :
1. Pertama Kamu ke Website Berikut https://anamaruchi.github.io/paper-thickness-calculation
2. Di Website tersebut, kamu pilih tipe kertas yang akan diprint untuk isi bukunya, Perhatikan Gambar Bawah

3. Lalu Isi Number of Papernya dengan Jumlah Pasti Kertas Nantinya, Misal di Bukunya ada 178 Halaman dan Cetaknya 2 Sisi, berarti 178 : 2 = 89 Lembar, Lalu Tekan Tombol Calculate, Perhatikan Gambar Bawah

4. Setelah Click Tombol Calculate, Akan Langsung Muncul Ketebalan Kertasnya dalam Centimeter, Misal Hasilnya adalah 0,82cm untuk Setting ke Punggung Hardcovernya Wajib Tambahkan 0,1cm dari Hasil Calculatenya menjadi 0,92cm / 0,9cm.

Untuk Rename File Cover Hard Cover bisa seperti dibawah

Hijau = Nama Customer
Kuning = Nama File yang berada didalam [HCL = Hard Cover Laminating]
Merah = Ukuran Jadi File
Biru = Bahan Print
Oren = Butuh Berapa Kali Printnya
Abu² = Rename File Wajib, Untuk Hardcover Laminatingnya apa
