Tutorial ID Card Laser

Download | File Module Tutorial ID Card Laser
ID Card adalah berukuran 5,4x8,6cm [Fix] jika bukan ukuran itu berarti bukan Ukuran ID Card, Untuk Setting ID Card Laser memiliki banyak urutan setting dibandingkan ID Card UV
Contoh Jadi Setting ID Card Laser 5,4x8,6cm, dengan Ukuran total selesai setting 5,9x9,4cm Untuk Sisi Depan Wajib Kasih Kress Mesin & Belakang Wajib Tidak Perlu Kasih Kress Mesin


Gambar diatas terdapat 3 warna, berikut :
Kuning = Untuk Ukuran Jadi Total Canvas File 5,9x9,4cm
Merah = Bleed Potong 2mm keliling
Hijau = Margin dari pinggir ukuran ID Card, Minimal 3mm


Jika Cetak ID Card Laser berjumlah diatas > 15pcs atau Tidak Muat di PVC A4

Penamaan File bisa seperti gambar diatas :
Hijau = Nama Customer
Kuning = Nama File yang berada didalam
Merah = Ukuran Jadi File
Ungu = Penamaan Sisi Depan & Belakang [Jika Cetak 2 Sisi] Wajib menjadi 2 PDF Terpisah
Biru = Bahan Print
Oren = Berapa Pcs Cetak
Abu² = Rename File Wajib untuk Print ID Card Laser
Jika Cetak ID Card Laser berjumlah dibawah < 10pcs untuk 1 Sisi & dibawah <5pcs untuk 2 Sisi

Lalu Untuk Penamaan File Jika Pakai PVC A4, Berikut Gambar di bawah :

Hijau = Nama Customer
Kuning = Nama File yang berada didalam
Merah = Ukuran Jadi File
Biru = Bahan Print
Oren = Berapa Pcs Cetak & Tambahkan Rename Jadi Untuk Pcs Pastinya
Abu² = Rename File Wajib untuk Print ID Card Laser

Untuk Layout A4, Kamu Wajib Layout Sendiri dan sudah jadi di PDF A4 Selesai Layout, Kamu Bebas setting layout di Coreldraw, Adobe Illustrator, atau apapun yang kamu bisa, asalkan hasilnya sama & rapih.
