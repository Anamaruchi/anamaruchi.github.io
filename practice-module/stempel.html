Tutorial Stempel

Download | File Module Tutorial Stempel

Stempel Merupakan Salah Satu Produk Jadi di Percetakan, Stempel digunakan untuk banyak Keperluan, Stempel Umum biasanya Stempel Jenis Flash yang dijual bebas. Pada Tutorial Ini Kamu akan Belajar Setting Stempel Jenis Flash.

Stempel Jenis Flash Umumnya Memiliki Warna Maksimal 3 Warna dalam 1 Stempel dan Tidak Bisa Berwana Gradasi/Gradient. Tempat Stempel Jenis Flash Memiliki 4 Bentuk Umum [Kotak, Persegi Panjang, Bulat dan Oval]

Tutorial disini saya akan menggunakan Software Adobe Illustrator, Kamu bebas menggunakan Software Lainnya yang kamu kuasai, Karena Point Utama Settingannya adalah Membuat Filenya Menjadi Vector untuk Print Stempelnya.
Catatan Penting: File Print Untuk Stempel Wajib Vector!
Cara Setting Stempel :
1. Pertama Buat Plot Untuk Membuat Vector Cuttingnya, Perhatikan Gambar Bawah

2. Selesai Buat Plot Untuk Membuat Vector Cuttingnya, Kamu Ubah Menjadi Vector, Perhatikan Gambar Bawah
3. Lalu Ubah Ke Ukuran Stempel Jadinya nanti, Perhatikan Panah Pada Gambar

4. Setelah Itu Kamu Buat Ukuran Untuk Tempat Stempelnya nanti berdasarkan Ukuran Muatnya Masuk Ke Ukuran Stempel Bentuk apa, Untuk Mengetahui Jenis ukuran Stempelnya nanti, Kamu Bisa Cek Pada Gambar Bawah
5. Jika Sudah Buat Plot Potong Berdasarkan Ukuran Nanti di Tempat Stempelnya dengan Stroke Warna Hitam Tebal 0,1pt, Perhatikan Panah Pada Gambar

6. Lalu Kamu Buat Canvasnya Menjadi UK A5, dan Layout Full seperti Contoh Pada Gambar Bawah

Note Penting :
1. Untuk File Stempel, Antara Character / Object Minimal Berjarak 0,1cm, Perhatikan Gambar Bawah

2. Misal Kamu Menggunakan Stempel Persegi Panjang dengan Ukuran 5,5x4,3cm, Berarti Area Stempelnya Adalah 5,2x4cm atau Dikurangin 0,3cm Keliling dengan Jarak 0,15cm tiap Sudut, Perhatikan Gambar Bawah


3. Buat File Vector Juga dengan Hasil Jadi Warnanya dengan Ukuran A4 Untuk di Print Pada Kertas HVS sebagai Approval Warna pada Customer Jika Customer Tidak Ada Contoh Warnanya, Perhatikan Gambar Bawah


Untuk Rename File Stempel bisa seperti dibawah
Hijau = Nama Customer
Kuning = Nama File yang berada didalam
Merah = Ukuran Jadi File
Biru = Bahan Print
Oren = Butuh Berapa Kali Printnya
Abu² = Rename File Print
