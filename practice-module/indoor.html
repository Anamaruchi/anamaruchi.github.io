Tutorial Indoor

Download | File Module Tutorial Indoor
Indoor adalah Produk yang dicetak Seperti Bahan Albatros / Stiker Ukuran Besar yang diperuntukkan untuk dipasang di Dalam Ruangan, Karena Point Utamanya diperuntukkan Memberikan Informasi pada Dalam Ruangan, walaupun bisa juga dipasang Luar Ruangan.

Ada Perbedaan Pada Hasil Cetak Outdoor dan Indoor :
Outdoor : Hasilnya Tidak Terlalu Tajam, dan Tidak diperkenankan jika Designnya Memiliki Tulisan Kecil
Indoor : Hasilnya Lebih Tajam dari Outdoor, dan Disarankan jika Designnya Memiliki Banyak Tulisan Kecil

Beberapa Point Setting Outdoor & Indoor :
• Jika Ukurannya Semakin Besar, Berarti Resolusinya Semakin Kecil [Contoh 200x100cm - Resolusi 150pixels]
• Jika Ukurannya Semakin Kecil, Berarti Resolusinya Semakin Besar [Contoh 60x180cm - Resolusi 300pixels]

Untuk Tutorial Ini, Saya Akan Menggunakan Software Adobe Photoshop, Untuk Setting Indoor tidak jauh berbeda dengan Outdoor, hanya saja Indoor bisa CMYK ataupun RGB Filenya, berbeda dengan Outdoor yang Wajib CMYK
Contoh Cetak X Banner dengan bahan Albatros 60x160cm

Cara Setting Cetak Indoor :
1. Pastikan Ukuran Cetak Sudah Sesuai, Jika Belum Ubah dulu dengan Menekan Ctrl + Alt + I pada Photoshop & Pastikan tidak ada gambar/tulisan yang pecah/blur pada file dikarenakan Indoor memiliki Lebih Ketajaman Hasil print dari pada Outdoor, Perhatikan pada Gambar Bawah

2. Pehatikan Sisi Tiap Sudut pada File, apakah terlalu pojok dengan pinggir atau tidak, Minimal adalah 4cm, dikarenakan Finishing X Banner akan ada Mata Ayam Tiap Sudut, Perhatikan Panah pada Gambar Bawah


Cara Save File Cetak Indoor :
1. Pergi Ke File, dan Pilih Save As, Perhatikan Panah pada Gambar Bawah
2. Pilih Format JPEG [Untuk Lebih Aman Print] Walau Bisa Juga PDF, Perhatikan Panah pada Gambar Bawah

3. Pilih Quality 12 Maximum, dan Format Options Baseline Standard [Wajib], Perhatikan Panah pada Gambar Bawah


Catatan: Untuk Print Indoor, Khusus File Print Bisa Berformat PDF Maupun JPG
Untuk Rename File Indoor bisa seperti dibawah
Hijau = Nama Customer
Kuning = Nama File yang berada didalam
Merah = Ukuran Jadi File
Biru = Bahan Print
Oren = Berapa Kali Cetak
Abu² = Jenis Finishingnya / Keterangan Tambahan

Jenis Finishing Dalam Cetak Indoor :
• Mata Ayam Pojok-Pojok / Standar
• Finishing X Banner [Berbeda dengan Mata Ayam Pojok-Pojok]
• Potong Pas Ukuran
• List Putih Keliling 5cm / Lebihan Bahan 5cm
• Tanpa Finishing / Lepas Potong Bahan
• Selongsong
