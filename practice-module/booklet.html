Tutorial Booklet

Download | File Module Tutorial Booklet
Booklet adalah salah satu Jenis Jilid/Binding pada Buku, Booklet adalah Binding yang menggunakan steples pada bagian tengah buku, seperti contoh Buku Belajar LKS.

Booklet memiliki hitungan jumlah pasti sebelum melakukan Settingan Booklet, Booklet dalam 1 Lembar harus terdiri dari 4 Halaman, Karena jika Halamannya Kurang akan terdapat Halaman yang di isi lembar kosong.

Contoh Hitung Halaman Booklet :
Customer Ingin Cetak Buku UK A5 Tertutup dengan Jilid Booklet dengan Covernya Di Print 1 Sisi, dan Isinya di Print 2 Sisi. File dari Customer Berjumlah 30 Halaman termasuk Cover Depan & Cover Belakang, tapi jika langsung di Setting Booklet Halaman tidak akan bertemu dan akan ngacak, Untuk Itu Kamu harus membuat menjadi 32 Halaman dahulu agar halamannya cocok dan sesuai.

30/4 = 7,5 ❌ [Hasilnya terdapat Desimal dengan Begitu Halaman belum Cocok/Cukup]
32/4 = 8 ✔️ [Hasilnya sudah tidak terdapat Desimal dengan Begitu Halaman sudah Sesuai]

Cara Setting Booklet :
1. Buka PDF File Booklet yang ingin disetting, Lalu Cek Halaman & Ukuran apakah sudah sesuai atau belum, Perhatikan Panah pada Gambar Bawah

2. Jika Halaman Belum Sesuai Kamu Konfirmasi dahulu kepada Customer, tapi Karena Customer ingin Covernya 1 Sisi Berdasarkan [Pernyataan Permintaan di atas], Kamu Berikan Kosongan Setelah Halaman 1 [Cover Depan] & Sebelum Halaman 30 [Cover Belakang] dengan Cara Click Kanan pada Halaman dan Pilih Insert Pages -> A Blank Page, Perhatikan Panah pada Gambar Bawah

3. Setelah Sudah Menjadi Halaman yang Sesuai, Kamu Pergi ke bagian menu atas, Plug-ins -> Create booklet, Perhatikan Panah pada Gambar Bawah

4. Pilih Option Berdasarkan, Perhatikan Gambar bawah

5. Setelah Melakukan Step 4, akan Muncul New Tab Selesai Setting Booklet, File yang awalnya A5 setelah booklet akan digabung menjadi A4 pada PDF, Perhatikan Panah pada Gambar Bawah

6. Extract Page Halaman 1 Pada Selesai Setting Booklet, Untuk Memisahkan File Print Cover, dan Save PDF Filenya, Perhatikan Panah pada Gambar Bawah

7. Lalu Hapus Halaman 1 & 2 pada PDF Booklet untuk Menyisakan Halaman Booklet Isi, dan Save PDF Filenya


Untuk Rename File Booklet bisa seperti dibawah

Hijau = Nama Customer
Kuning = Nama File yang berada didalam
Merah = Ukuran Jadi File
Biru = Bahan Print
Ungu = Isi Booklet Sudah pasti BB [Bolak Balik], Terkecuali Cover Bisa 2 Sisi maupun 1 Sisi
Oren = Butuh Berapa Kali Printnya
Abu² = Jika hasil butuh laminating, Jika tidak laminating tidak perlu direname [Disarankan Laminating jika bahan cover semakin tebal, agar saat cover dilipat tidak retak/pecah]
