Tutorial Kartu Nama

Download | File Module Tutorial Kartu Nama

Kartu Nama Standar adalah ber-ukuran 9x5,5cm, Selain itu ada juga 8,5x5cm, jika ada ukuran lain berarti masuk ke ukuran Custom dan bukan masuk ke Paket Kartu Nama

Untuk Setting Kartu Nama, Pastikan buat bleed potong terlebih dahulu, jika dari filenya belum ada bleednya.


Berikut gambar di atas adalah contoh Kartu Nama dengan Ukuran 9x5,5cm

Untuk Setting, buat bleed pada file kartu nama dengan keliling 4mm [bisa menggunakan photoshop dengan metode [content aware], menjadi ukuran 9,4x5,9cm dan membuat kress potong mesin seperti di contoh gambar atas.
Warna Merah pada gambar diatas adalah area bleed yang dibuat dengan 4mm keliling, dengan begitu area potong terdapat 2mm untuk potongan mesin

Warna Hijau pada gambar diatas adalah margin dari pinggir ukuran kartu nama, jika terlalu pojok edit dahulu agar tidak terlalu pojok sebelum membuat bleed potong, jarak minimal dari pojok ukuran adalah 3mm, namun semakin jauh semakin bagus, agar saat pemotongan tidak ada isi/tulisan yang terpotong.

Penamaan File bisa seperti gambar diatas :
Hijau = Nama Customer
Kuning = Nama File yang berada didalam
Merah = Ukuran Jadi File
Biru = Bahan Kertas
Ungu = BB jika 2 sisi [Bolak Balik], Jika tidak 2 sisi, tidak usah tulis BB
Oren = Berapa Box Cetak
Abu² = Jika hasil butuh laminating, Jika tidak laminating tidak perlu direname
