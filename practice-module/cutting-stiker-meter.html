Tutorial Cutting Stiker Meter

Download | File Module Tutorial Cutting Stiker Meter
Cutting Stiker Meter adalah Print Stiker dengan Ukuran diatas A3+ atau Yang sudah tidak masuk Print di Ukuran Kertas A3+ lalu membutuhkan Finishing Cutting seperti Kisscutting Stiker A3+

Cutting Stiker Meter termasuk Produk Indoor, dikarenakan Printnya di Mesin Indoor, Berbeda dengan Kisscutting A3+ yang langsung selesai setelah di Kisscutting, Cutting Stiker Meter setelah di Cutting Membutuhkan Prosess Lanjutan, yaitu Prosess Pemasangan Masking pada Stikernya.

Tutorial disini saya akan menggunakan Software Adobe Illustrator, Kamu bebas menggunakan Software Lainnya yang kamu kuasai, Karena Point Utama Settingannya Hampir Sama dengan Kisscutting, Untuk Cutting Stiker Meter bisa dengan RGB maupun CMYK.

Note Penting :
1. File Cutting Wajib Format Vector
2. File Print Boleh PNG/JPG/JPEG/Vector

Cara Setting Cutting Stiker Meter :
1. Pertama Buat Plot Untuk Membuat Vector Cuttingnya, Perhatikan Gambar Bawah

2. Selesai Buat Plot Untuk Membuat Vector Cuttingnya, Kamu Ubah Menjadi Vector, Perhatikan Gambar Bawah

3. Pastikan Ukuran Sudah Sesuai yang Diinginkan, Perhatikan Gambar Bawah

4. Lalu Ubah Canvas dengan Menambahkan 3cm Keliling, Misal Ukuran Stikernya 100x22,5cm -> Canvasnya Menjadi 103x25,5cm, Agar Canvasnya tidak sama dengan Ukuran Stikernya, Perhatikan Gambar Bawah

5. Lalu Sesuaikan File Print dengan Menambahkan Stroke Keliling 1cm atau 0,5cm tiap Sudutnya, Perhatikan Gambar Bawah

6. Lalu Buat 2 Artboard/Canvas berdasarkan [1 Artboard/Canvas Untuk File Print - Gambar Nomer 2] dan [1nya lagi Artboard/Canvas Untuk File Cutting - Gambar Nomer 3], Lalu Pastikan Juga File Cutting Penempatannya sama dengan File Print agar saat di cutting pas/presisi [Lihat Gambar Nomer 1], Perhatikan Gambar Bawah

7. Lalu Save PDF dengan Menjadi 2 Bagian File PDF [1 PDF Untuk Print & 1 PDF Untuk Cutting]
Catatan: Untuk Print Indoor, Khusus File Print Bisa Berformat PDF Maupun JPG
Untuk Rename File Cutting Stiker Meter bisa seperti dibawah

Hijau = Nama Customer
Kuning = Nama File yang berada didalam
Merah = Ukuran Jadi File
Biru = Bahan Print
Oren = Butuh Berapa Kali Printnya
Abu² = Rename File Wajib, Untuk Cutting Stiker Meter
Ungu = File Untuk Cuttingnya
