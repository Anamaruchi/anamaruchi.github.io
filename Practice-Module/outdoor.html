Tutorial Outdoor

Download | File Module Tutorial Outdoor

 Outdoor adalah Produk yang dicetak Seperti Bahan Spanduk / Banner yang diperuntukkan untuk dipasang di Luar Ruangan, Karena Point Utamanya Untuk Dilihat dari Jauh bukan dari Dekat.

Ada Perbedaan Pada Hasil Cetak Outdoor dan Indoor :
Outdoor : Hasilnya Tidak Terlalu Tajam, dan Tidak diperkenankan jika Designnya Memiliki Tulisan Kecil
Indoor : Hasilnya Lebih Tajam dari Outdoor, dan Disarankan jika Designnya Memiliki Banyak Tulisan Kecil

Beberapa Point Setting Outdoor & Indoor :
• Jika Ukurannya Semakin Besar, Berarti Resolusinya Semakin Kecil [Contoh 200x100cm - Resolusi 150pixels]
• Jika Ukurannya Semakin Kecil, Berarti Resolusinya Semakin Besar [Contoh 60x180cm - Resolusi 300pixels]

Untuk Tutorial Ini, Saya Akan Menggunakan Software Adobe Photoshop
Contoh Cetak Spanduk dengan bahan Outdoor Flexy 280gr

Cara Setting Cetak Outdoor :
1. Pastikan Ukuran Cetak Sudah Sesuai, Jika Belum Ubah dulu dengan Menekan Ctrl + Alt + I pada Photoshop, Perhatikan Panah pada Gambar Bawah
2. File Outdoor Wajib CMYK, Jika Filenya Belum CMYK, Kamu ubah dulu ke CMYK, Perhatikan Panah pada Gambar Bawah


Catatan Penting Warna Pada Cetak Outdoor :
• Warna Biru pada Layar, Saat di Cetak akan Berubah Ke Warna Ungu, Selalu Konfirmasi pada Customer apakah Filenya Nanti Warna Biru atau Ungu, Terkecuali Jika Customer Memang Ingin Warna Ungu, Tetapi Jika Ingin Warna Biru, Kamu Harus Mengurangi Warna Magenta (M) Pada File menjadi 80%

• Warna Oren pada Layar, Saat di Cetak akan Berubah Ke Warna Merah, Selalu Konfirmasi pada Customer apakah Filenya Nanti Warna Merah atau Oren, Terkecuali Jika Customer Memang Ingin Warna Merah, Tetapi Jika Ingin Warna Oren, Kamu Harus Mengurangi Warna Magenta (M) Pada File menjadi 50~60%

• Lalu ada juga, Warna Hitam pada Layar, Saat di Cetak akan Rawan Tinta Bercak/Tidak Rata/Bleber Hasilnya, Jika Blacknya diatas 90%, Untuk Itu Wajib diturunkan Menjadi 80% Blacknya

Cara Menurunkan Warna Pada Photoshop :
1. Cek Warna yang ingin diturunkan pada File, Menggunakan Color Picker Pada Photoshop, Perhatikan Panah pada Gambar Bawah

2. Lalu Ke Selective Color pada Photoshop, Perhatikan Panah pada Gambar Bawah

3. Pilih Warna yang ingin diturunkan pada Selective Color, Perhatikan Panah pada Gambar Bawah

4. Lalu Isi pada Bagian Warna yang ingin diturunkan, Perhatikan Panah pada Gambar Bawah

5. Hasil Warna Setelah Diturunkan Agar Warnanya Menjadi Biru Saat di Cetak, Pehatikan Gambar Bawah 


Cara Save File Cetak Outdoor :
1. Pergi Ke File, dan Pilih Save As, Perhatikan Panah pada Gambar Bawah

2. Pilih Format JPEG [Wajib Untuk Outdoor], Perhatikan Panah pada Gambar Bawah

3. Pilih Quality 12 Maximum, dan Format Options Baseline Standard [Wajib], Perhatikan Panah pada Gambar Bawah


Untuk Rename File Outdoor bisa seperti dibawah
Hijau = Nama Customer
Kuning = Nama File yang berada didalam
Merah = Ukuran Jadi File
Biru = Bahan Print
Oren = Berapa Kali Cetak
Abu² = Jenis Finishingnya

Jenis Finishing Dalam Cetak Outdoor :
• Mata Ayam Pojok-Pojok / Standar
• Finishing X Banner [Berbeda dengan Mata Ayam Pojok-Pojok]
• Potong Pas Ukuran
• List Putih Keliling 5cm / Lebihan Bahan 5cm
• Tanpa Finishing / Lepas Potong Bahan
