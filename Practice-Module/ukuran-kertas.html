Ukuran Kertas

Panduan Ukuran Kertas Standar

Memahami ukuran kertas standar sangat penting untuk desain dan percetakan yang akurat.

1. Seri A (ISO 216)

  • A0: 84,1 x 118,9cm
  • A1: 59,4 x 84,1cm
  • A2: 42 x 59,4cm
  • A3: 29,7 x 42cm
  • A3+: 31,5 x 47,5cm
  • A4: 21 x 29,7cm
  • A5: 14,8 x 21cm
  • A6: 10,5 x 14,8cm

2. Seri B (ISO 216)

  • B0: 100 x 141,4cm
  • B1: 70,7 x 100cm
  • B2: 50 x 70,7cm
  • B3: 35,3 x 50cm
  • B4: 25 x 35,3cm
  • B5: 17,6 x 25cm

3. Ukuran Khusus Indonesia

  • F4/Folio: 21,6 x 33cm
  • Legal: 21,6 x 35,6cm
  • Letter: 21,6 x 27,9cm
  • Quarto: 21,6 x 27,5cm

4. Ukuran Kartu

  • Kartu Nama: 9 x 5,5cm
  • ID Card: 5,4 x 8,6cm

5. Catatan Penting

  • Selalu tambahkan (Minimal) bleed 2mm keliling untuk hasil print yang akan dipotong
  • Gunakan safe area (Minimal) 3mm dari tepi untuk teks/gambar penting
  • Perhatikan orientasi: Portrait (Tinggi) vs Landscape (Lebar)
Catatan: Berlatih Untuk Menghafal Seluruh Ukuran Kertas secara bertahap, agar kamu bisa lebih menguasai hal selanjutnya.
