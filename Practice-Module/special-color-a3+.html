Tutorial Special Color A3+

Download | File Module Tutorial Special Color A3+

Special Color A3+ adalah Warna dengan Tinta Special yaitu Tinta White, Tinta Gold, dan Tinta Silver. Tinta Jenis Tersebut Harus disetting dahulu sebelum masuk ke Prosess Printing.

Untuk Setting Special Color pada A3+, tidak jauh beda dengan Setting Spot Color/Channel pada UV, hanya Penamaan Spot Color/Channelnya saja yang beda dari UV. Tapi disini saya hanya memberikan Tutorial berdasarkan Software Adobe Photoshop, karena cara settingnya sama saja jika kamu menggunakan Adobe Illustrator, Coreldraw atau Software Lainnya, Karena Fokus Settingannya Memberikan Spot Color/Channel yang ingin di tempatkan Tinta Specialnya.

Cara Setting Special Color A3+ :
1. Buka Adobe Photoshop dan Masukan File yang ingin di Setting Special Colornya lalu Pastikan Ukurannya sudah Sesuai yang diinginkan, Perhatikan Gambar Bawah

2. Select Bagian yang Ingin di Setting Special Colornya, Perhatikan Gambar Bawah

3. Lalu Ubah Menjadi Warna Putih dahulu bagian yang ingin di Setting Special Colornya, Agar Saat diprint nanti dibawah Special Colornya tidak ada Warna yang Ditiban.

4. Setelah diubah ke Warna Putih, Kamu Pergi ke Tab Channels, Perhatikan Gambar Bawah

5. Bikin Layer baru di Tab Channel, Perhatikan Gambar Bawah
6. Klick Kanan pada Filenya, dan Pilih Select Invers, lalu Tekan Ctrl + I, Perhatikan Gambar Bawah

7. Setelah Melakukan Step 6, Pastikan Hasilnya Menjadi, Perhatikan Gambar Bawah

8. Lalu Pada Layer Channel, Ubah Menjadi Name "Gold", Pilih Spot Color, dan Solidity 100%, Perhatikan Gambar Bawah

9. Lalu Nyalakan Semua Layer pada Tab Channel, Perhatikan Gambar Bawah

10. Terakhir Tinggal Save PDF dengan Settingan yang sama, Perhatikan Panah pada Gambar Bawah

Catatan Penting :
• Untuk Tinta Gold, Nama Spot Channelnya "Gold" Perhatikan Penulisannya, "G" Besar, "old" Kecil
• Untuk Tinta Silver, Nama Spot Channelnya "Silver" Perhatikan Penulisannya, "S" Besar, "ilver" Kecil
• Untuk Tinta White, Nama Spot Channelnya "White" Perhatikan Penulisannya, "W" Besar, "hite" Kecil

Cara Cek Spot Special Color pada PDF, Untuk Mengetahui Apakah Setting File Berhasil atau Tidak :
1. Buka PDF yang Ingin di Cek, Lalu Pergi ke Tab Tools, Perhatikan Panah pada Gambar Bawah

2. Setelah Klick Print Production, Klick Output Preview pada bagian Kanan Menu di PDF, Perhatikan Panah pada Gambar Bawah

3. Arahkan Cursor Mouse pada Halaman Print yang terdapat Spot Channel Colornya, Jika berubah menjadi 100% berarti berhasil, Perhatikan Panah pada Gambar Bawah


Untuk Rename File Special Color A3+ bisa seperti dibawah

Hijau = Nama Customer
Kuning = Nama File yang berada didalam
Merah = Ukuran Jadi File
Biru = Bahan Print
Oren = Berapa Kali Cetak
Ungu = Special Color yang digunakan
Abu² = Untuk Keterangan Tambahan, Laminating Jika Laminating, Potong Jika Potong
